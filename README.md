# DrumAsia — "Session One"

Website for **DrumAsia** — jamming studio, recording studio, live venue and
backline rental, Desa Sri Hartamas, Kuala Lumpur. Est. 2014. *Play, Practice and
Perform.*

The build is organised by milestone; see `docs/README.md` for setup, and
`docs/OPEN-QUESTIONS.md` for the client-confirmation checklist (domain advisory
first).

- **Live internal route:** `/en/console` — the design system.
- **Stack:** Next.js 15 · TypeScript · Tailwind v4 · next-intl · Framer Motion.
- **Transaction layer:** WhatsApp only. No payment integration, ever.

```
npm install && npm run dev   # → http://localhost:3000/en
```
